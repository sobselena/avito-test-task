# 🚀 Запуск проекта

### 1. Клонировать репозиторий проекта

``` bash
git clone https://github.com/sobselena/avito-test-task.git
```

### 2. Перейти в папку проекта

``` bash
cd avito-test-task
```

### 3. Установить зависимости

``` bash
npm install
```
### 4. Запустить Проект

``` bash
npm run dev
```
--- 

### 5.  Клонировать репозиторий сервера
``` bash
  git clone https://github.com/sobselena/avito-test-task-server.git
```
### 6. Перейти в папку сервера

``` bash
cd avito-test-task-server
```
### 7. Запустить Сервер

``` bash
npm run start
```

После запуска приложение будет доступно по адресу:

    http://localhost:5173
