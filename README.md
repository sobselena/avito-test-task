# 🚀 Запуск проекта

### Настройка переменных окружения LLM

1. Зарегистрируйтесь и получите ключ на платформе **Open Router**
2. Создайте файл `.env` в корне проекта
3. Добавьте ключ в `.env`:

```bash
VITE_LLM_KEY=your_key
```

---

## 🖥️ Frontend

1. Клонируйте репозиторий проекта:

```bash
git clone https://github.com/sobselena/avito-test-task.git
```

2. Перейдите в папку проекта:

```bash
cd avito-test-task
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект:

```bash
npm run dev
```

---

## ⚙️ Backend

> Рекомендуется скачать сервер с указанного репозитория, так как в исходный сервер были внесены некоторые улучшения.

1. Клонируйте репозиторий сервера:

```bash
git clone https://github.com/sobselena/avito-test-task-server.git
```

2. Перейдите в папку сервера:

```bash
cd avito-test-task-server
```

3. Запустите сервер:

```bash
npm run start
```

---

После запуска фронтенда приложение будет доступно по адресу:

```bash
http://localhost:5173
```
